# LexFlow

A web app for learning English vocabulary with **spaced repetition**.

Tracks how well you know each word and schedules reviews automatically — correct answers push a word further out, mistakes bring it back sooner.

## Stack

**Frontend:** React, TypeScript, Vite, React Router, Tailwind CSS, shadcn/ui, TanStack Query, Zustand, React Hook Form, Zod

**Backend:** Supabase (Auth, PostgreSQL)

## Getting started

```bash
npm install
npm run dev
```
